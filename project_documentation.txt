# Linux USB Device Driver with Asynchronous I/O

## Project Overview

Designed and developed a custom USB device using Raspberry Pi Pico 2 (RP2350) and implemented a Linux USB device driver to establish bidirectional communication between the device firmware and Linux userspace.

The project focuses on understanding the Linux USB subsystem, asynchronous USB transfers, URB lifecycle management, kernel-to-userspace data handling, concurrency, and safe USB device disconnection/reconnection.

## Hardware and Software

- **USB Device:** Raspberry Pi Pico 2 (RP2350, ARM Cortex-M33)
- **Firmware:** Embedded C/C++, Pico SDK, TinyUSB
- **Operating System:** Linux (Kali Linux)
- **Driver:** Linux Kernel USB subsystem
- **USB Interface:** Vendor-specific interface
- **Endpoints:** Bulk OUT (`0x03`) and Bulk IN (`0x83`)
- **USB Speed:** Full Speed (12 Mbps)
- **Tools:** ARM GCC, CMake, Make, Vim, Git

### Asynchronous Bulk IN Data Path

Implemented asynchronous Bulk IN transfers using URBs.

Data flow:

USB Device → Bulk IN URB → Completion Callback → RX Workqueue → FIFO Buffer → Character Device → Userspace

The completion callback executes in USB completion context and transfers received data into a workqueue for processing in process context.

The RX workqueue:
- Processes received packets outside atomic context
- Copies received data into a kernel FIFO
- Uses mutex protection for FIFO synchronization
- Wakes blocked userspace readers when data becomes available

### Character Device Interface

Created a character device interface at `/dev/usb_demo` to enable userspace communication with the USB device.

Implemented:
- `open()`
- `read()`
- `write()`
- `release()`
- `poll()`

Features:
- Blocking userspace reads
- FIFO-based data buffering
- Userspace-to-device Bulk OUT communication
- Asynchronous write URBs
- Poll-based readiness notification
- Device-disconnect-aware read and write handling

### Buffering and Concurrency

Implemented a FIFO buffer with:
- 4096-byte capacity
- Head, tail, and count management
- Mutex synchronization
- FIFO wraparound handling
- Full-buffer handling

Implemented asynchronous userspace writes using individually allocated URBs, transfer buffers, and write contexts.

Added synchronization and lifetime management to handle:
- Concurrent writes
- USB device disconnection during active transfers
- Pending URB cancellation
- Device lifetime management using reference counting
- Safe cleanup of asynchronous transfer resources

### Disconnect and Reconnection Handling

Implemented safe USB disconnect handling.

During disconnect:
- Mark the device as disconnected
- Prevent new userspace writes
- Cancel pending asynchronous write URBs
- Kill active USB URBs
- Flush pending RX workqueue tasks
- Wake blocked readers
- Remove the character device
- Release USB driver resources

Implemented device reconnection support through USB re-enumeration and driver re-probing.
